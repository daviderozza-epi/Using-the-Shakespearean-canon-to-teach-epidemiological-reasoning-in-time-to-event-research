# Using-the-Shakespearean-canon-to-teach-epidemiological-reasoning-in-time-to-event-research
Evidence-based medicine requires strong epidemiological reasoning and a priori decision strategies before any data analysis and statistical modelling: who enters the study population, when follow-up begins, how exposures and outcomes are defined, and which biases may affect their measurement determine the findings.
The closed cohort of Shakespearean characters, where death is anything but rare, offers an intuitive setting in which these 
choices are explicit and their consequences directly observable.
We constructed a dataset of characters from 26 Shakespearean histories, tragedies and romances, recording occupation, social status, narrative context, and time-to-death or censoring.
Follow-up was measured in character-acts. 
Reproducible R code allows users to modify analytical choices and observe their consequences. We also developed a catalogue of epidemiological biases and modelling problems to be explored using the following code and the open-access dataset of Shakespearean characters.
